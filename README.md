# Güvercin Belediye Meclisi

> Cami avlusundaki güvercinlerin ekmek kırıntısı bütçesini, uçuş koridorunu ve kedi diplomasisini oylayan resmi görünümlü belediye meclisi.

Bu yazılım **ISO-GUV-1923** standardına göre hazırlanmıştır. Standart yoktur. Standart olduğunu söylüyoruz, o kadar.

## Ne işe yarar?

- Güvercin meclis üyelerini kura ile atar.
- Gündemi açar (ekmek kırıntısı, çeşme suyu, kedi ateşkes protokolü).
- Oylar. Çoğunlukla kendi kanadının lehine.
- Tutanak basar. Tutanak uçup gider.

## Kurulum

```bash
python3 meclis.py
```

Başka bir şey istemez. İnternet de istemez. Güvercinler zaten çevrimiçidir.

## Örnek çıktı

```
=== 23 EYLÜL 2026 OLAĞANÜSTÜ OTURUM ===
Başkan: Kırık-Kanat Mehmet
Gündem 1: Avludaki susam dağıtımı
SONUÇ: KABUL (7 evet, 2 hayır, 1 uçtu gitti)
```

## Sık sorulan sorular

**Bu bilimsel mi?**  
Hayır. Ama ciddi duruyor.

**Güvercinler gerçekten oy kullanıyor mu?**  
Kullanmıyor. Yazılım kullanıyor. Farkını kimse anlamaz.

**Siyaset var mı?**  
Yok. Sadece ekmek kırıntısı. (Kırıntı da bir tercihtir.)
